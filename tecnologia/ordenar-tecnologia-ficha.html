Ordena: Algoritmos y Evolución

Ordena los pasos de un algoritmo, la historia de la computación y las unidades de información.

PrimariaTecnología · 4 rondas

🎮 Jugar en pantalla

Nombre:Fecha:

Numera cada elemento según el orden correcto, empezando por el 1.

1. Ordena los pasos del algoritmo para lavarse las manos

  • ___ Frotar las manos
  • ___ Poner jabón
  • ___ Secarse las manos
  • ___ Mojarse las manos
  • ___ Abrir el grifo
  • ___ Enjuagar

2. Ordena del invento más antiguo al más reciente

  • ___ Ábaco
  • ___ Calculadora mecánica
  • ___ Teléfono inteligente
  • ___ Computadora personal
  • ___ Computadora de válvulas

3. Ordena las unidades de información de menor a mayor

  • ___ Megabyte
  • ___ Terabyte
  • ___ Bit
  • ___ Byte
  • ___ Kilobyte
  • ___ Gigabyte

4. Ordena los pasos para enviar un correo electrónico

  • ___ Escribir la dirección del destinatario
  • ___ Escribir el asunto y el mensaje
  • ___ Pulsar «Enviar»
  • ___ Abrir el correo
  • ___ Pulsar «Redactar»

Respuestas: Ordena: Algoritmos y Evolución

  1. Abrir el grifo → Mojarse las manos → Poner jabón → Frotar las manos → Enjuagar → Secarse las manos. Un algoritmo es eso: una serie de pasos en un orden preciso.
  2. Ábaco → Calculadora mecánica → Computadora de válvulas → Computadora personal → Teléfono inteligente.
  3. Bit → Byte → Kilobyte → Megabyte → Gigabyte → Terabyte. Un byte son 8 bits; cada unidad siguiente equivale a unas mil de la anterior.
  4. Abrir el correo → Pulsar «Redactar» → Escribir la dirección del destinatario → Escribir el asunto y el mensaje → Pulsar «Enviar».
