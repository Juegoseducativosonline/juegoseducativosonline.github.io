Máquinas Simples

Palancas, poleas, ruedas, rampas y cuñas.

4.º–5.ºTecnología · 12 preguntas

🎮 Jugar en pantalla

Nombre:Fecha:

Rodea con un círculo la letra de la respuesta correcta.

1. ¿Qué es una máquina simple?

  1. Una máquina con motor eléctrico
  2. Una computadora pequeña
  3. Un robot
  4. Un objeto sencillo que ayuda a hacer menos esfuerzo al mover algo

2. Un subibaja es un ejemplo de…

  1. Palanca
  2. Rueda y eje
  3. Tornillo
  4. Polea

3. ¿Qué máquina simple usamos al subir un objeto pesado por una rampa?

  1. Palanca
  2. Cuña
  3. Plano inclinado
  4. Polea

4. El hacha y el cuchillo son ejemplos de…

  1. Rueda y eje
  2. Palanca
  3. Polea
  4. Cuña

5. ¿Qué máquina simple permite subir un balde tirando de una cuerda que pasa por una rueda?

  1. Tornillo
  2. Plano inclinado
  3. Polea
  4. Cuña

6. ¿Qué máquina simple forman las ruedas de una bicicleta con su eje?

  1. Palanca
  2. Rueda y eje
  3. Plano inclinado
  4. Cuña

7. Un tornillo es, en realidad…

  1. Una palanca doblada
  2. Una rueda aplastada
  3. Una polea pequeña
  4. Un plano inclinado enrollado

8. ¿Cuál de estos objetos funciona como una palanca?

  1. Un balde
  2. Una rampa
  3. Unas tijeras
  4. Un clavo

9. Una carretilla tiene su punto de apoyo en la rueda. ¿Qué máquina simple es?

  1. Palanca
  2. Cuña
  3. Plano inclinado
  4. Polea

10. ¿Para qué usa una grúa un sistema de varias poleas?

  1. Para enfriar su motor
  2. Para medir el peso
  3. Para cortar metal
  4. Para levantar cargas muy pesadas con menos esfuerzo

11. ¿Qué es una máquina compuesta?

  1. Una máquina rota
  2. Una formada por varias máquinas simples, como la bicicleta
  3. Una que tiene una sola pieza
  4. Una que funciona sin ninguna fuerza

12. ¿Cómo se llama el punto sobre el que gira una palanca?

  1. Eje de la rueda
  2. Carga
  3. Punto de apoyo o fulcro
  4. Potencia

Respuestas: Máquinas Simples

  1. d) Un objeto sencillo que ayuda a hacer menos esfuerzo al mover algo
  2. a) Palanca Tiene un punto de apoyo en el centro, como todas las palancas.
  3. c) Plano inclinado Recorremos más distancia, pero con menos esfuerzo.
  4. d) Cuña La cuña tiene forma de filo y sirve para cortar o separar.
  5. c) Polea La polea cambia la dirección de la fuerza: tiramos hacia abajo y el balde sube.
  6. b) Rueda y eje
  7. d) Un plano inclinado enrollado
  8. c) Unas tijeras Cada hoja de las tijeras gira sobre el tornillo del centro, que es el punto de apoyo.
  9. a) Palanca
  10. d) Para levantar cargas muy pesadas con menos esfuerzo
  11. b) Una formada por varias máquinas simples, como la bicicleta
  12. c) Punto de apoyo o fulcro

Objetivo: Identificar palancas, poleas, planos inclinados, cuñas y tornillos en objetos cotidianos y explicar cómo reducen el esfuerzo.

DBA: Ciencias Naturales · 4.º · DBA 2: «Comprende los efectos y las ventajas de utilizar máquinas simples en diferentes tareas que requieren la aplicación de una fuerza.»
