La Computadora

Hardware, software, dispositivos de entrada y salida, y la memoria.

3.º–5.ºTecnología · 12 preguntas

🎮 Jugar en pantalla

Nombre:Fecha:

Rodea con un círculo la letra de la respuesta correcta.

1. ¿Qué es el hardware?

  1. Internet
  2. Los programas
  3. Las partes físicas de la computadora, las que se pueden tocar
  4. Los archivos guardados

2. ¿Qué es el software?

  1. Los cables
  2. La pantalla
  3. Los programas e instrucciones que usa la computadora
  4. El teclado y el ratón

3. ¿Cuál de estos es un dispositivo de entrada?

  1. La impresora
  2. El monitor
  3. Los altavoces
  4. El teclado

4. ¿Cuál de estos es un dispositivo de salida?

  1. El escáner
  2. El ratón
  3. La impresora
  4. El micrófono

5. ¿Qué parte se considera el «cerebro» de la computadora porque procesa la información?

  1. La memoria USB
  2. El teclado
  3. El monitor
  4. El procesador (CPU)

6. ¿Qué es un sistema operativo?

  1. Un tipo de cable
  2. Un videojuego
  3. Una página web
  4. El programa principal que controla la computadora

7. ¿Qué pasa con lo que hay en la memoria RAM al apagar la computadora?

  1. Se envía por internet
  2. Se guarda para siempre
  3. Se borra
  4. Se imprime

8. ¿Cuál de estas cantidades de información es la mayor?

  1. 1 kilobyte
  2. 1 gigabyte
  3. 1 megabyte
  4. 1 byte

9. ¿Qué dispositivo sirve para guardar archivos y llevarlos a otra computadora?

  1. El monitor
  2. El ratón
  3. Una memoria USB
  4. Los altavoces

10. ¿Qué es un navegador web?

  1. Un virus
  2. Un teclado especial
  3. Un tipo de cable
  4. Un programa para visitar páginas de internet

11. ¿Para qué sirve un antivirus?

  1. Para imprimir
  2. Para proteger la computadora de programas dañinos
  3. Para navegar más rápido
  4. Para enfriar la computadora

12. En Windows, ¿qué combinación de teclas sirve para copiar?

  1. Alt + F4
  2. Ctrl + C
  3. Ctrl + V
  4. Ctrl + Z

Respuestas: La Computadora

  1. c) Las partes físicas de la computadora, las que se pueden tocar
  2. c) Los programas e instrucciones que usa la computadora
  3. d) El teclado Los de entrada meten información en la computadora; los de salida la muestran.
  4. c) La impresora
  5. d) El procesador (CPU)
  6. d) El programa principal que controla la computadora Windows, macOS, Linux y Android son sistemas operativos.
  7. c) Se borra Por eso hay que guardar los archivos en el disco antes de apagar.
  8. b) 1 gigabyte Un gigabyte equivale a unos mil megabytes, y un megabyte a unos mil kilobytes.
  9. c) Una memoria USB
  10. d) Un programa para visitar páginas de internet Chrome, Firefox, Edge y Safari son navegadores.
  11. b) Para proteger la computadora de programas dañinos
  12. b) Ctrl + C Ctrl + V pega, Ctrl + Z deshace y Alt + F4 cierra la ventana.
