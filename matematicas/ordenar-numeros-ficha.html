Ordena: Números y Operaciones

Ordena enteros, fracciones y potencias, y el orden de las operaciones.

6.º–8.ºMatemáticas · 4 rondas

🎮 Jugar en pantalla

Nombre:Fecha:

Numera cada elemento según el orden correcto, empezando por el 1.

1. Ordena de menor a mayor

  • ___ 0,75
  • ___ 0
  • ___ −2
  • ___ −5
  • ___ 1/2
  • ___ 3

2. Ordena estas fracciones de menor a mayor

  • ___ 3/4
  • ___ 2/3
  • ___ 1/3
  • ___ 1/2
  • ___ 1/4

3. Ordena de menor a mayor

  • ___ 10³
  • ___ 1
  • ___ 0,1
  • ___ 10⁻²
  • ___ 10²

4. Para resolver 2 + 3 × (4 − 1)², ¿en qué orden se hacen las operaciones?

  • ___ Multiplicación
  • ___ Paréntesis
  • ___ Potencia
  • ___ Suma

Respuestas: Ordena: Números y Operaciones

  1. −5 → −2 → 0 → 1/2 → 0,75 → 3.
  2. 1/4 → 1/3 → 1/2 → 2/3 → 3/4. 0,25 < 0,33 < 0,5 < 0,67 < 0,75.
  3. 10⁻² → 0,1 → 1 → 10² → 10³. 10⁻² es 0,01.
  4. Paréntesis → Potencia → Multiplicación → Suma. (4 − 1) = 3; 3² = 9; 3 × 9 = 27; 2 + 27 = 29.
